# SquirrelForge Output Rules

Version: 1.0.0
Status: Stable
Owner: Engine Maintainers
Depends On: Validation, Project Configuration
Used By: Engine and Agents
Last Updated: 2026-07-01

Final output must lead with the outcome, identify changed artifacts, report validation evidence and unresolved risks, use canonical terminology, avoid unsupported completion claims, and contain no secrets or internal-only data.
