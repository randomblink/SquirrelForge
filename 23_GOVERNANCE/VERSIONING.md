# SquirrelForge Versioning

Version: 1.0.0
Status: Stable
Owner: Governance Maintainers
Depends On: Change Management
Used By: All components
Last Updated: 2026-07-01

Use semantic versions: major for incompatible contracts or behavior, minor for backward-compatible capability, and patch for backward-compatible corrections. Document versions describe the contract they specify, not merely editorial revisions.
