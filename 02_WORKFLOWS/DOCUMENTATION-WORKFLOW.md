# Documentation Workflow

Version: 1.0.0
Status: Stable
Owner: Documentation Maintainers
Depends On: Output Rules, Template Standard
Used By: Documentation Agent
Last Updated: 2026-07-01

1. Identify audience, purpose, scope, and source of truth.
2. Select an applicable template and gather verified facts.
3. Draft with canonical terms, explicit prerequisites, and actionable examples.
4. Verify technical accuracy, links, metadata, accessibility, and consistency.
5. Record reviewer, validation evidence, and version impact.
6. Publish through the applicable change and release process.
