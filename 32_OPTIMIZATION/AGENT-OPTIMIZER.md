# SquirrelForge Agent Optimizer

## Purpose

The Agent Optimizer analyzes and improves the performance, efficiency, and effectiveness of AI agents operating within SquirrelForge. It evaluates decision quality, planning effectiveness, reasoning performance, memory utilization, tool usage, collaboration patterns, and execution outcomes to recommend measurable improvements.

The Agent Optimizer does not directly alter agent behavior or decision-making logic. It develops evidence-based optimization recommendations and coordinates approved improvements through the Optimization Manager while preserving governance, explainability, safety, and auditability.

---

# Responsibilities

- Analyze agent performance.
- Evaluate decision quality.
- Assess planning effectiveness.
- Review reasoning efficiency.
- Analyze memory utilization.
- Evaluate tool usage.
- Improve agent collaboration.
- Recommend agent optimizations.
- Record optimization activity.
- Enforce optimization governance.

# Agent Optimization Workflow

1. Receive agent optimization request.
2. Collect agent performance data.
3. Evaluate decision quality.
4. Analyze reasoning and planning.
5. Review memory and tool utilization.
6. Identify optimization opportunities.
7. Develop optimization recommendations.
8. Submit recommendations for validation.
9. Record audit information.
10. Publish optimization status.

# Data Protection

The Agent Optimizer must:

- Protect agent metadata.
- Preserve decision history.
- Exclude confidential operational data.
- Enforce governance policies.
- Maintain audit integrity.

---

# Safety Rules

The Agent Optimizer must never:

- Modify agent behavior without approval.
- Reduce explainability.
- Weaken governance controls.
- Compromise decision quality.
- Remove required safety mechanisms.
- Ignore observability evidence.
- Delete audit records.

---

# Failure Handling

If agent optimization fails:

- Preserve optimization evidence.
- Record optimization failures.
- Notify the Optimization Manager.
- Retry analysis when appropriate.
- Escalate persistent failures.
- Support rollback planning.
- Maintain audit continuity.
