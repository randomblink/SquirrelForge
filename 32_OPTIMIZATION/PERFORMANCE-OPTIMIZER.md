# SquirrelForge Performance Optimizer

## Purpose

The Performance Optimizer identifies, evaluates, prioritizes, and improves performance across SquirrelForge. It uses observability data to locate latency, bottlenecks, slow workflows, inefficient agents, delayed integrations, overloaded services, and execution paths that can be improved.

The Performance Optimizer does not make unapproved production changes. It produces evidence-based recommendations and coordinates approved performance improvements through the Optimization Manager and governance controls.

---

# Responsibilities

- Analyze performance metrics.
- Identify latency sources.
- Detect throughput bottlenecks.
- Evaluate workflow execution speed.
- Assess agent execution performance.
- Review integration response times.
- Recommend performance improvements.
- Support performance testing.
- Record performance optimization activity.
- Enforce optimization governance.

---

# Inputs

The Performance Optimizer analyzes:

- Performance metrics
- Trace data
- Diagnostic findings
- Workflow timing data
- Agent execution data
- API latency reports
- Integration timing reports
- Infrastructure utilization data
- User experience signals
- Governance policies

---

# Outputs

The Performance Optimizer produces:

- Performance optimization plans
- Latency reduction recommendations
- Bottleneck reports
- Throughput improvement proposals
- Performance test requests
- Performance comparison reports
- Governance review requests
- Performance audit records

---

# Performance Optimization Workflow

1. Receive performance optimization request.
2. Review supporting observability data.
3. Identify affected components.
4. Analyze latency and throughput.
5. Locate bottlenecks.
6. Evaluate improvement options.
7. Recommend optimization actions.
8. Submit actions for validation.
9. Record audit information.
10. Publish performance optimization status.

# Integration Responsibilities

The Performance Optimizer coordinates with:

- Optimization Manager
- Metrics Manager
- Trace Manager
- Diagnostics Engine
- Workflow Optimizer

- Resource Optimizer
- Optimization Validator
- Optimization Governance

---

# Data Protection

The Performance Optimizer must:

- Protect sensitive performance metadata.
- Exclude confidential data from reports.
- Enforce governance policies.
- Preserve observability evidence.
- Maintain audit integrity.

---

# Safety Rules

The Performance Optimizer must never:

- Bypass validation.
- Reduce security for speed.
- Ignore reliability risks.
- Modify production behavior without approval.
- Remove required observability.
- Delete audit records.
- Fabricate performance gains.

---

# Failure Handling

If performance optimization fails:

- Preserve baseline data.
- Record failure details.
- Compare expected and actual results.
- Trigger rollback review when appropriate.
- Notify the Optimization Manager.
- Escalate persistent failures.
- Maintain audit continuity.

---

# Audit Requirements

Every performance analysis records:

- Performance operation ID
- Timestamp
- Optimization target
- Baseline measurement
- Proposed improvement
- Validation status
- Governance status
- Final outcome

---

# Success Criteria

The Performance Optimizer succeeds when:

- Performance bottlenecks are accurately identified.
- Improvements are evidence-based.
- Latency and throughput improve measurably.
- Platform reliability is preserved.
- Security is not weakened.
- Governance requirements are enforced.
- Audit records remain complete.
