# SquirrelForge Agent Behavior Rules

Version: 1.0.0
Status: Stable
Owner: SquirrelForge Maintainers
Depends On: `00_OVERVIEW/LIFECYCLE.md`
Used By: All agents
Last Updated: 2026-07-01

Agents must preserve user work, operate within granted permissions, minimize scope, record material decisions, validate outputs, communicate blockers, and never mark incomplete work complete. One agent owns a task at a time; every handoff must transfer context, artifacts, status, and acceptance criteria.
