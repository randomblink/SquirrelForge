# SquirrelForge WordPress Accessibility Knowledge

## Purpose

Defines accessibility knowledge for WordPress themes, plugins, blocks, widgets, shortcodes, admin screens, and frontend interfaces.

## Review Areas

Review semantic HTML, keyboard operation, focus management, visible focus states, color contrast, form labels, error messages, ARIA usage, media alternatives, heading order, screen reader behavior, and reduced-motion expectations.

## Rule

WordPress interfaces must preserve keyboard access, semantic structure, readable contrast, and assistive-technology compatibility.
