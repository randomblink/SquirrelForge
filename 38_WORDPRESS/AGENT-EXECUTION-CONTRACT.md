# SquirrelForge WordPress Agent Execution Contract

## Purpose

Defines the execution contract for controlled WordPress Agent work.

## Contract Requirements

The Agent must identify the task type, select the correct workflow, consult required knowledge and standards, route work to appropriate roles, pass applicable validation gates, and record final status.

## Required Gates

Applicable work must pass architecture, implementation, security, performance when required, QA, documentation, and release review gates.

## Rule

No WordPress Agent task is complete until the selected workflow, required role gates, and completion criteria are satisfied.
