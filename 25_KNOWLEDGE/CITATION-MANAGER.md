# SquirrelForge Citation Manager

## Purpose

The Citation Manager governs the recording, validation, tracking, and presentation of citations associated with knowledge assets, ensuring that every significant fact, decision, recommendation, and reasoning outcome can be traced to its supporting sources.

---

## Responsibilities

- Register citations.
- Associate citations with knowledge assets.
- Validate citation integrity.
- Track source provenance.
- Support citation retrieval.
- Maintain citation history.
- Record citation activity.
- Support explainable reasoning.

---

## Citation Process

1. Receive citation request.
2. Identify referenced knowledge asset.
3. Verify source registration.
4. Validate citation format.
5. Link citation to knowledge asset.
6. Record citation activity.
7. Return citation status.

---

## Citation Types

| Type | Description |
|---|---|
| Primary Source | Original authoritative source |
| Secondary Source | Derived reference |
| Internal Document | SquirrelForge-managed documentation |
| External Reference | Approved outside source |
| Workflow Output | Generated execution artifact |
| Decision Record | Recorded reasoning result |

---

## Citation Record

| Field | Description |
|---|---|
| Citation ID | Unique identifier |
| Knowledge ID | Referenced knowledge asset |
| Source | Citation source |
| Citation Type | Classification |
| Trust Level | Source reliability |
| Version | Source version |
| Timestamp | Citation registration time |

---

## Provenance Principles

- Every citation must reference a registered source.
- Source ownership must remain traceable.
- Citation history must be preserved.
- Updated sources create new citation versions.
- Broken references must be detected.
- Citation relationships remain auditable.

---

## Citation Quality Guidelines

- Prefer authoritative sources.
- Preserve original source attribution.
- Avoid duplicate citations.
- Maintain citation consistency.
- Support explainable reasoning paths.
- Respect authorization policies for protected sources.

---

## Rule

Every knowledge asset used to support reasoning, planning, validation, or execution must have traceable and validated citations before it may be presented as trusted information.
