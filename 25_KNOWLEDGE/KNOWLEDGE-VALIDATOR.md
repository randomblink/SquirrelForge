# SquirrelForge Knowledge Validator

## Purpose

The Knowledge Validator verifies the accuracy, completeness, consistency, trustworthiness, freshness, and structural integrity of knowledge before it becomes available for retrieval, reasoning, planning, validation, or execution.

---

## Responsibilities

- Validate knowledge integrity.
- Verify source authenticity.
- Assess trustworthiness.
- Check completeness.
- Detect conflicting knowledge.
- Verify citation integrity.
- Record validation results.
- Approve or reject knowledge activation.

---

## Validation Process

1. Receive knowledge for validation.
2. Verify registration.
3. Validate structure and metadata.
4. Verify source authenticity.
5. Validate citations.
6. Check consistency with existing knowledge.
7. Assess freshness.
8. Record validation results.
9. Approve or reject activation.

---

## Validation Categories

| Category | Description |
|---|---|
| Structure | Required fields and metadata |
| Source | Authenticity and provenance |
| Citation | Valid citation relationships |
| Completeness | Required information present |
| Consistency | No conflicting knowledge |
| Freshness | Information remains current |
| Trust | Meets required trust level |

---

## Validation Status

| Status | Meaning |
|---|---|
| Pending | Awaiting validation |
| Valid | Passed all required checks |
| Warning | Minor issues identified |
| Failed | Validation unsuccessful |
| Rejected | Not approved for use |

---

## Validation Record

| Field | Description |
|---|---|
| Validation ID | Unique identifier |
| Knowledge ID | Validated knowledge asset |
| Validator | Responsible validation component |
| Result | Pass / Warning / Fail |
| Trust Level | Assigned trust classification |
| Timestamp | Validation time |
| Notes | Validation observations |

---

## Validation Checklist

- Knowledge is registered.
- Required metadata exists.
- Sources are verified.
- Citations are valid.
- Trust requirements are satisfied.
- Conflicts have been resolved.
- Freshness requirements are met.

---

## Rule

No knowledge asset may become available for retrieval or reasoning until it has successfully passed validation and received an approved validation record.
