## Purpose

The Reflection Engine evaluates completed work to identify improvements, capture lessons learned, and strengthen future workflows.

## Responsibilities

- Review completed tasks.
- Evaluate workflow effectiveness.
- Identify successes and failures.
- Detect repeated issues.
- Recommend improvements.
- Capture reusable knowledge.
- Submit approved improvements to the Knowledge Manager.

## Reflection Process

1. Receive a completed and validated task.
2. Compare the result against the original goal.
3. Review validation outcomes.
4. Identify strengths and weaknesses.
5. Record lessons learned.
6. Recommend workflow or template improvements.
7. Forward reusable knowledge to the Knowledge Manager.

## Reflection Model

| Field | Description |
|---|---|
| Goal | Original objective |
| Result | Final outcome |
| Validation | Passed / Failed |
| Successes | What worked well |
| Issues | Problems encountered |
| Improvements | Suggested enhancements |
| Lessons Learned | Reusable insights |
| Follow-up Actions | Recommended next steps |

## Reflection Questions

- Was the original goal achieved?
- Were all validation checks successful?
- Were unnecessary steps performed?
- Could the workflow be simplified?
- Should a new workflow or template be created?
- Can any part of this work be reused?

## Rule

Every completed and validated task should be reviewed before it is archived, ensuring continuous improvement of the SquirrelForge system.
