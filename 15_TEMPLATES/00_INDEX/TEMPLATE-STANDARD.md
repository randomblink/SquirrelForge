# SquirrelForge Template Standard

Version: 1.0.0
Status: Stable
Owner: Documentation Maintainers
Depends On: Governance and Output Rules
Used By: Template authors
Last Updated: 2026-07-01

Templates must state purpose, use canonical terminology, mark placeholders clearly, avoid project-specific secrets or assumptions, identify required and optional fields, and include validation guidance. Template changes follow governance and versioning policy.
