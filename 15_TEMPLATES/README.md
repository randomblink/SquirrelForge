## Purpose
Provides reusable, governed starting points for project artifacts.

## Components
Index and standards, issue and pull-request templates, planning and release documents, and project scaffolds.

## Execution Order
Choose template → copy → replace placeholders → validate against standard → use.

## Dependencies
Template Standard, project configuration, and applicable workflow.

## Rules
Never edit a reusable source template for one project instance. Unresolved placeholders block release.
