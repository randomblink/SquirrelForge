# Review Library

## Purpose

This directory preserves sequential `SF-REVIEW-XXX` evidence and decisions. Review records are stable historical authorities; their filenames and numbering should not be reorganized casually.

## Review Classes

- Author reviews examine an artifact against its governing requirements.
- Independent reviews re-derive important claims rather than accepting the author's account.
- Category consistency reviews evaluate a complete taxonomy and entry set as one system.
- Baseline reviews certify a complete category or framework state.
- Governance and repository reviews evaluate specifications, architecture, or repository integrity.

## Finding a Review

Use the numeric identifier cited by the artifact. When browsing by purpose, search filenames for `AUTHOR`, `INDEPENDENT`, `CONSISTENCY`, `BASELINE`, `TAXONOMY`, `SPEC`, or `VERIFICATION`.

## Placement Rule

Add the next available sequential review identifier. Preserve prior findings and historical quotations; corrections belong in a new review or revision record, not silent edits to history.
