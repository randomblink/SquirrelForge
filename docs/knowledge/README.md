# Knowledge Library

## Purpose

This directory contains durable WordPress diagnostic knowledge and the runtime evidence used to confirm or correct it.

## Contents

| Directory | Contents |
|---|---|
| [`wp-errors/`](wp-errors/) | Production-ready `WP-ERROR-XXX` diagnostic entries |
| [`verifications/`](verifications/README.md) | `WP-VERIFICATION-XXX` Reference Implementation records |

## Reading Order

Begin with the relevant `WP-ERROR` entry. Follow its taxonomy and review references when ownership or certification matters. Read the associated verification record when a claim has been exercised against a disposable WordPress runtime.

## Placement Rule

Do not add duplicate WP-ERROR authorities merely to preserve prose. Merge verified information into the existing owner through the governed correction process.
