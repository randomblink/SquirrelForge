# SquirrelForge Capabilities

This directory contains capability records describing repeatable SquirrelForge workflows. Capabilities are descriptive records, not a parallel governance system: they use the repository's existing document lifecycle, review process, validation gates, and evidence standards.

## Capability framework

See [`SF-CAPABILITY-FRAMEWORK.md`](SF-CAPABILITY-FRAMEWORK.md) for the required structure, evidence expectations, and lifecycle integration.
