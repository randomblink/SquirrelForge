# Validation Records

## Purpose

This directory contains specialized validation artifacts that do not belong to the `WP-VERIFICATION-XXX` Reference Implementation series.

## Reading Guidance

Use these records when auditing the specific agent or framework behavior named by the file. WordPress error-entry runtime evidence belongs under `docs/knowledge/verifications/` instead.

## Placement Rule

Do not create a validation document when an existing verification, review, test, or baseline artifact already owns the evidence.
