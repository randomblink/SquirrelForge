## Purpose

Episodic Memory records completed work, preserving the history of tasks, decisions, outcomes, and lessons learned for future reference.

## Responsibilities

- Record completed tasks.
- Preserve execution history.
- Record major decisions.
- Store validation outcomes.
- Capture lessons learned.
- Support future audits and retrospectives.

## Episodic Memory Contents

| Item | Description |
|---|---|
| Task ID | Unique task identifier |
| Goal | Original objective |
| Execution Plan | Plan used to complete the task |
| Agents Involved | Agents that participated |
| Outcome | Final result |
| Validation | Validation status |
| Lessons Learned | Key takeaways |
| Completion Date | Date finished |

## Recording Process

1. Receive completed task.
2. Verify validation passed.
3. Record execution history.
4. Store important decisions.
5. Capture lessons learned.
6. Index the record.
7. Archive for future retrieval.

## Retrieval Uses

- Similar task lookup
- Historical review
- Regression analysis
- Process improvement
- Audit support

## Rule

Only completed and validated tasks should be stored in Episodic Memory. Incomplete or failed work should remain in the task history until resolved or archived separately.
