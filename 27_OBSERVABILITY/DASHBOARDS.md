# SquirrelForge Dashboard Manager

## Purpose

The Dashboard Manager presents operational data collected throughout SquirrelForge in a clear, unified, and actionable manner, enabling users, administrators, and agents to monitor system health, workflow progress, performance, security, and overall platform status.

---

## Responsibilities

- Present operational dashboards.
- Display workflow status.
- Visualize execution performance.
- Report integration health.
- Display security posture.
- Summarize AI provider usage.
- Present operational trends.
- Support drill-down analysis.

---

## Dashboard Process

1. Receive dashboard request.
2. Identify requested dashboard.
3. Retrieve current operational data.
4. Validate data freshness.
5. Generate dashboard views.
6. Present summarized information.
7. Support detailed inspection.

---

## Dashboard Categories

| Dashboard | Purpose |
|---|---|
| System Health | Overall operational status |
| Workflow | Active and completed workflows |
| Execution | Running actions and execution performance |
| Integrations | External service health |
| AI Providers | Model availability, usage, and cost |
| Security | Authentication, authorization, and security events |
| Validation | Validation success and failure trends |
| Releases | Build and deployment status |
| Observability | Logs, metrics, traces, and alerts |

---

## Dashboard Widgets

| Widget | Description |
|---|---|
| Status Summary | Overall system condition |
| Active Workflows | Current workflow execution |
| Recent Alerts | Latest operational alerts |
| Performance Trends | Historical performance metrics |
| Integration Health | External service availability |
| AI Usage | Model usage and costs |
| Resource Utilization | CPU, memory, storage, and network |
| Error Summary | Recent failures and resolutions |

---

## Dashboard Record

| Field | Description |
|---|---|
| Dashboard ID | Unique identifier |
| Dashboard Type | Selected operational view |
| Generated At | Dashboard generation time |
| Data Range | Time period represented |
| Data Freshness | Age of displayed data |
| Status | Successfully generated / Failed |

---

## Dashboard Principles

- Present actionable information.
- Prioritize operational health.
- Highlight critical conditions first.
- Support filtering and drill-down.
- Display current data whenever possible.
- Maintain consistent presentation across dashboards.

---

## Rule

Every operational dashboard must present accurate, current, and traceable information derived from approved observability components before it is displayed.
