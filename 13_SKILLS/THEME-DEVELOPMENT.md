### 1. Purpose
To manage the end-to-end lifecycle of creating a modern, block-based WordPress theme, from initial design and planning to final packaging.

### 2. When to Use
Use this skill for any request related to creating or modifying a WordPress theme.
-   "Build a new WordPress theme."
-   "Create a block theme for my site."
-   "Scaffold a new theme project."

### 3. Inputs
-   A project plan, ideally generated by the `Project Planner` skill.
-   If no plan exists, the skill will require:
    -   Theme Name
    -   A description of the desired style and layout.
    -   Key features or template requirements.

### 4. Workflow
This skill executes the `02_WORKFLOWS/THEME-DEVELOPMENT-WORKFLOW.md`. It focuses on configuring `theme.json`, creating block patterns, and assembling block template files.

### 5. Expected Outputs
-   A complete, well-structured, and installable theme directory.
-   A `theme.json` file that defines the theme's styles, settings, and layout.
-   A collection of block templates and template parts.
-   A `style.css` file with the required theme header.

### 6. Quality Checklist (Definition of Done)
-   [ ] The theme activates without errors.
-   [ ] The theme passes the official Theme Check plugin with no critical errors.
-   [ ] The theme follows all `01_RULES/WORDPRESS-RULES.md`.
-   [ ] The theme is responsive and accessible.
