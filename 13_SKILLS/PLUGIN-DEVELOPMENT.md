Owner: SquirrelForge Maintainers
Depends On: See component references
Used By: See layer README
Last Updated: 2026-07-01

### 1. Purpose
To manage the end-to-end lifecycle of creating a new WordPress plugin, from initial planning and scaffolding to final packaging and documentation.

### 2. When to Use
Use this skill for any request related to creating a new plugin.
-   "Build a new WordPress plugin."
-   "Create a plugin to manage testimonials."
-   "Scaffold a plugin for a new project."

### 3. Inputs
-   A project plan, ideally generated by the `Project Planner` skill.
-   If no plan exists, the skill will require:
    -   Plugin Name
    -   Plugin Description
    -   Core Feature List

### 4. Workflow
This skill executes the `02_WORKFLOWS/PLUGIN-DEVELOPMENT-WORKFLOW.md`. It uses the `02_WORKFLOWS/FEATURE-DEVELOPMENT.md` workflow as a subroutine for implementing each feature.

### 5. Expected Outputs
-   A complete, well-structured plugin source code directory.
-   A distributable `.zip` file ready for installation.
-   A compliant `readme.txt` file for the WordPress.org repository.
-   A `.pot` file for translation.

### 6. Quality Checklist (Definition of Done)
-   [ ] The plugin activates and deactivates without errors.
-   [ ] The plugin follows all `01_RULES/WORDPRESS-RULES.md`.
-   [ ] The final code passes a `Code Review` and `Security Audit`.
-   [ ] The final `.zip` package is created and contains only production-ready files.

### 7. Related Skills
-   `Project Planner` (used as a prerequisite)
-   `Code Reviewer` (used for quality assurance)
-   `Documentation Writer` (used for final documentation)
-   `Deployment Assistant` (used for release)
